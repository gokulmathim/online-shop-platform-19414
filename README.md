# Project Repository

This repository contains an e-commerce platform with a React frontend.

- Frontend (React): online-shop-platform-19414/ecommerce_frontend
  - See its README for setup and environment variables.

Run the frontend:
1) cd online-shop-platform-19414/ecommerce_frontend
2) npm install
3) Create a .env from .env.example and set REACT_APP_API_BASE_URL to your backend, e.g., http://localhost:5000/api
4) npm start
